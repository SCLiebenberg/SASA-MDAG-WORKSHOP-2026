# Sourcing Multivariate Climate Data

Materials for the SASA MDAG workshop on sourcing, processing and modelling GSOD station data and ERA5 reanalysis data.

## Participants: start here

Please work through the **[preparation checklist](PREPARATION.md)** before the workshop. It covers registering on the Copernicus Climate Data Store and installing R and the required packages.

## Contents

| Folder | What it holds |
|---|---|
| `setup/` | Package installation and setup check script |
| `gsod-app/` | Shiny app for downloading GSOD data and scoring station data quality |
| `era5-app/` | Shiny app for requesting ERA5 data from the CDS |
